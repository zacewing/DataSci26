How it was tested

Many different lifters

Each simulated lifter gets a random starting strength, rate of progress, schedule (2 to 5 days a week), day-to-day noise, and randomly placed plateaus, regressions and deloads. Because the simulation knows each lifter's true strength, we know exactly when they really stalled.

Tune on some, test on others

Settings were chosen on one group of lifters. Every score on this page comes from a separate group the tuning never saw. Scoring on the same data you tuned on makes a model look better than it is.

Honest error bars

Intervals come from resampling whole lifters (a cluster bootstrap). One lifter's weeks are related to each other, so treating every week as independent would make the intervals look falsely narrow.

A baseline to beat

A model only earns its complexity if it beats something simple. For plateaus that's the gym rule "no new best in 3 weeks"; for predictions it's "same as last session".

Plateau detection

What the measures mean

Precision: when it says "plateau", how often that's true. Recall: of the weeks a lifter was really stalled, how many it flagged. F1: one score that balances the two. Plateaus caught: share of real plateaus (3+ weeks) flagged at some point, allowing a -week lag. False alarms: share of flagged stretches where the lifter was actually progressing the whole time.

The trade-off

Each gray dot is one combination of settings (window length × stall threshold × weeks in a row), scored on the tuning lifters. Up and to the right is better. Hover a dot to see its settings.

Where it struggles

Next-session prediction

Error is the average miss as a percentage of the lifter's e1RM, so strong and weaker lifters count equally. The p-value is from a Wilcoxon signed-rank test: same lifters, model vs. baseline.

Limitations

  • It's simulated. The lifters follow rules I wrote. Real training is messier: injuries, program changes, missed weeks. These results show the methods work when the world behaves like the simulation, not that it always does.
  • The prediction model can only learn what the simulation contains. Sleep and soreness affect simulated performance because I built them in, so finding that effect isn't a discovery about real lifters.
  • "Truly stalled" is a definition. Here it means true strength grew under 0.25% a week over two weeks. A different cutoff would shift every score.
  • e1RM is an estimate. Epley's formula is less accurate above about 10 reps, and RPE is self-reported.

Reproduce it

Everything on this page comes from one command, with fixed random seeds so it gives the same numbers every time:

python -m src.benchmark
